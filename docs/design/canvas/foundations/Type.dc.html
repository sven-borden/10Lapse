Tabular figures

Proportional: the counter wobbles as digits change 0111 / 0742 0888 / 0742
Tabular: every digit is the same width 0111 / 0742 0888 / 0742

Applies to frame counters, time codes, the speed readout, export percent, file sizes. Frame numbers are zero-padded to the width of the total.
